# PDF RAG Chatbot

This is a Streamlit-based PDF RAG chatbot.
Users can upload a PDF and ask questions based only on its content.

## Features
- PDF upload
- Context-aware answers
- No hallucinations
- Built using LLM + RAG

## Run Locally
```bash
pip install -r requirements.txt
streamlit run level_4_pdf_rag/app.py
